## Overview

**SIGNIFY** is an AI-powered sign language translation system designed to reduce communication barriers between sign-language users and non-sign-language speakers.

The project combines a **Python-based Artificial Intelligence and Computer Vision pipeline** with a **cross-platform Flutter mobile application** to process sign-language gestures and transform them into accessible digital output.

SINGNIFY was developed as an **end-to-end AI product**, integrating machine learning, visual processing, application development, and real-time interaction into a unified system.

---

## ✨ Core Features

- Real-time sign language recognition
- AI-powered gesture classification
- Computer Vision processing
- Machine Learning inference
- Cross-platform Flutter mobile application
- Text-based translation output
- Speech-enabled output
- Real-time interaction workflow
- AI and mobile application integration
